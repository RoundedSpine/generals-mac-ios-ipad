# Development Diary - October 2026

## 2026-10-24: Unsigned iOS IPA workflow

Added a manually dispatched macOS GitHub Actions build for the iOS device
preset. It packages an unsigned IPA without Apple credentials or retail game
assets and uploads build diagnostics. The packaging script now supports
`--unsigned`, strips existing signatures, creates the Payload archive, and
checks embedded library references. The existing signed mode stays available.

Pushes to `ci/ios-unsigned-ipa` also start the build so the initial workflow
can run before it exists on the default branch.

The first macOS run installed all dependencies and configured successfully,
then stopped because copying `sdl3.pc` to `SDL3.pc` targets the same file on
the runner's case-insensitive filesystem. Guarded that copy with Bash's file
identity check. Also aligned vcpkg's cache environment with the restored
directory and save dependency binaries after configuration even if the
subsequent engine build fails.

The second macOS run compiled the iOS engine successfully, then failed during
packaging because `lipo -verify_arch arm64 <file>` parsed the filename as an
additional architecture. Moved the input file before `-verify_arch` and made
the mocked tool reject the original argument order to cover the regression.

Local validation covers shell/workflow syntax and packaging behavior with
mocked Apple tools. The GitHub macOS runner has validated engine compilation;
completed IPA packaging and sideloaded device behavior remain unverified.

Added a PowerShell asset collector for the user's Windows installation. It
copies archives and data folders into a new transfer directory, stages font
filenames expected by the engine, and refuses existing destinations or linked
assets. The source installation is left untouched.

Reviewed the iOS startup and deployment path after the LiveContainer logs and
subsequent direct-install purple-texture report. Fixed debug allocator
alignment, unchecked module-path failure, hosted-image driver paths, opaque
FILE copying and omitted code-only renderer configuration. Added startup
checkpoints and compiled regression harnesses. Findings and validation limits
are in `docs/WORKDIR/audit/IOS_SIDELOAD_STARTUP_REVIEW_2026-10-24.md`.

Added requested Increased Memory Limit and Extended Virtual Addressing keys to
the iOS wrapper's entitlement file. Unsigned artifacts ship that file beside
the IPA for external signing; signed packaging retains the wrapper's signed
entitlements as before. Tests check both keys in the exported plist. Actual
capability grants still depend on provisioning, the signing tool, the OS and,
for hosted apps, the host process.
