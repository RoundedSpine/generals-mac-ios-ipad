## 2026-10-27: Real ordinary-search loop on an exclusive worker

Separated the actual A* loop from ordinary-search preparation, success/failure
processing, Path/PathNode construction, optimization and retail recovery. Added
one synchronous exclusive executor. Main releases its scratch claim, waits without
pumping engine callbacks while the worker binds and runs the loop, then reclaims
the context before finalization. This computes real gameplay paths, unlike the
historical occupancy-query validator. Current context/record memory is borrowed
exclusively; no second map or search arena is allocated.

Preserve floating-point environment, context restoration on exceptions, existing
record limits and request scheduling. Pause/debug/nested/unavailable modes use the
caller. Startup/environment setup errors fall back before search mutations.
Crusher searches require the existing SquishCollide key via a new read-only probe;
do not prewarm it by inserting a key and changing allocation order. Worker-loop
occupancy checks bypass shadow sampling. No work survives the synchronous call;
shutdown joins the idle executor before engine memory release. Enable the option
only on experiment/ios-mod-testing.

This is a real ordinary-loop worker, but **not the full Reimagined parallel pipeline**.
Main waits, so it does not add parallel search throughput and adds handoff cost.
Closest/safe/attack/hierarchy remain serial, and prediction, overlapping independent
jobs and precomputed-result validation remain future work. Device performance and
