# Development Diary - October 2026

## 2026-10-24: Unsigned iOS IPA workflow

Added a manually dispatched macOS GitHub Actions build for the iOS device
preset. It packages an unsigned IPA without Apple credentials or retail game
assets and uploads build diagnostics. The packaging script now supports
`--unsigned`, strips existing signatures, creates the Payload archive, and
checks embedded library references. The existing signed mode stays available.

Local validation covers shell/workflow syntax and packaging behavior with
mocked Apple tools. A full Xcode build and sideloaded device validation cannot
run on this Linux cloud machine and remain unverified.
