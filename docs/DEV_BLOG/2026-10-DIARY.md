# Development Diary - October 2026

## 2026-10-24: Unsigned iOS IPA workflow

Added a manually dispatched macOS GitHub Actions build for the iOS device
preset. It packages an unsigned IPA without Apple credentials or retail game
assets and uploads build diagnostics. The packaging script now supports
`--unsigned`, strips existing signatures, creates the Payload archive, and
checks embedded library references. The existing signed mode stays available.

Pushes to `ci/ios-unsigned-ipa` also start the build so the initial workflow
can run before it exists on the default branch.

The first macOS run installed all dependencies and configured successfully,
then stopped because copying `sdl3.pc` to `SDL3.pc` targets the same file on
the runner's case-insensitive filesystem. Guarded that copy with Bash's file
identity check. Also aligned vcpkg's cache environment with the restored
directory and save dependency binaries after configuration even if the
subsequent engine build fails.

The second macOS run compiled the iOS engine successfully, then failed during
packaging because `lipo -verify_arch arm64 <file>` parsed the filename as an
additional architecture. Moved the input file before `-verify_arch` and made
the mocked tool reject the original argument order to cover the regression.

Local validation covers shell/workflow syntax and packaging behavior with
mocked Apple tools. The GitHub macOS runner has validated engine compilation;
completed IPA packaging and sideloaded device behavior remain unverified.

Added a PowerShell asset collector for the user's Windows installation. It
copies archives and data folders into a new transfer directory, stages font
filenames expected by the engine, and refuses existing destinations or linked
assets. The source installation is left untouched.

Reviewed the iOS startup and deployment path after the LiveContainer logs and
subsequent direct-install purple-texture report. Fixed debug allocator
alignment, unchecked module-path failure, hosted-image driver paths, opaque
FILE copying and omitted code-only renderer configuration. Added startup
checkpoints and compiled regression harnesses. Findings and validation limits
are in `docs/WORKDIR/audit/IOS_SIDELOAD_STARTUP_REVIEW_2026-10-24.md`.

Added requested Increased Memory Limit and Extended Virtual Addressing keys to
the iOS wrapper's entitlement file. Unsigned artifacts ship that file beside
the IPA for external signing; signed packaging retains the wrapper's signed
entitlements as before. Tests check both keys in the exported plist. Actual
capability grants still depend on provisioning, the signing tool, the OS and,
for hosted apps, the host process.

## 2026-10-25: Texture loading and shared archive fallback

Persistent purple textures after successful initialization led to the texture
loader: Unix ThreadClass starts no worker while the loader queues background
tasks. Use the existing synchronous completion path when no worker is running.
Also search shared base-Generals archives when Zero Hour loads from cwd, and
log bounded missing-texture names. Compiled regression tests cover inactive
and active worker dispatch plus cwd/explicit asset-root fallback. Device
rendering and subsequent crash behavior remain to be retested.

Fixed the subsequent iOS compile failure in missing-texture diagnostics:
`Get_Full_Path()` returns StringClass, so fprintf requires its `.str()` buffer.
Added a compiled regression harness for the actual missing-texture handler with
format warnings treated as errors.

Added a separate PowerShell collector for base Generals archives. It stages
all root .big files under ZH_Generals, refuses existing/nested destinations
and linked archives, and detects a Zero Hour-only source. The original game
installation remains untouched; tested with sample paths and archive files.

Added a standalone combined PowerShell collector with both user-provided game
paths as defaults. It validates both sources and fonts before creating output,
keeps Zero Hour archives at the root and base archives under ZH_Generals, and
leaves existing installations and output directories untouched.

Removed the LiveContainer-specific path changes at the user's request after
complete base-game data resolved the rendering/crash symptoms. Restored Apple's
normal executable-path lookup, argv-based app resources, SDL's default Vulkan
loader and the original executable-relative DXVK iOS patch. Kept bounded path
failure handling, allocator/stdio fixes, shared asset lookup, texture fallback,
packaging/config and entitlement support. Updated the path regression harness
for standalone executable lookup; all 12 local tests pass. New device validation
is still needed for the rebuilt IPA.

Removed the synchronous texture-loading fallback at the user's request. The
original Begin_Load/background-queue path is restored, and the log claiming
synchronous loading and its fallback-specific regression test were removed.
Shared base-archive lookup and missing-texture diagnostics remain. No background
worker implementation was added; the resulting IPA needs device comparison
with the working build using identical complete game assets.

Replaced Unix ThreadClass startup/stop/yield/thread-ID stubs with a joined
std::thread worker, atomic state and cooperative shutdown. Stop warns after its
time budget and still joins rather than cancelling a thread with engine locks
held. Priority changes are best effort within the current scheduler's range.
Texture queues now lock empty checks, and texture shutdown joins before taking
the worker's background lock. The texture worker stops before its derived
object is destroyed. Kept the legacy cursor GPU worker disabled on Unix so this
CPU-loader change does not introduce off-thread graphics calls. The removed
synchronous texture fallback remains removed.

Compiled tests cover real ThreadClass lifecycle, immediate stop/restart,
self-stop while the owner joins, exception cleanup, cooperative timeout,
concurrent queue transfer and texture shutdown ordering. Full iOS compilation
and device performance/gameplay validation still depend on the new CI run and
phone testing; no measured performance improvement is claimed.
